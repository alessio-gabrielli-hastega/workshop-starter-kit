# Quaderno degli Esercizi - Workshop Software

Benvenuti! Questo workspace vi accompagnerà per tutte le 5 lezioni del corso.

## Setup Iniziale (Lezione 1)
1. Apri questa cartella in VS Code.
2. Apri il terminale (Terminale > Nuovo Terminale).
3. Esegui: `npm install`

---
Ogni cartella contiene i file per le rispettive lezioni. Segui le indicazioni del docente per sapere quale file aprire!
